Generated by scripts/build_carrier_phone_metadata.py:
- phone-regions.json contains country calling codes, example allocation templates and
  full mobile/fixed-line number validation patterns for 245 regions.
- cn-mobile-cities.tsv.gz contains 110917 exact seven-digit Chinese mobile prefixes,
  city labels and original operator allocation. Entries with more-specific geographic
  children and ambiguous operator mappings are excluded. Fixed-line area codes are not
  used to invent mobile numbers. The included mapping covers 340 distinct data labels.
- City labels retain upstream historic names; this is not a current administrative-city
  census. Ported numbers may have different current operators. The dataset is not an
  authoritative live allocation registry. Generated numbers may already be assigned.

The original Apache 2.0 license is included in libphonenumber-LICENSE.txt.
No external network requests are made when generating or reading a configured number.
