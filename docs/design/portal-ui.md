# Portal 界面设计

主题来自传送枪参考图的绿色、灰色设备和圆润轮廓。导航顶部使用名称与简化几何标识，不使用原始插画。

## 配色

- 页面背景：`#F3FAF0`；正文：`#182018`。
- 主色：`#326B2D`；按钮白字对比度约 6.41:1。
- 选中容器：`#DDF7D5`；容器文字：`#163A18`。
- 深色背景：`#101A12`；主色：`#8ED27F`。
- 错误与停止操作沿用语义错误色。

Compose 默认使用绿色主题，原紫色通过 `PortalColorStyle.CLASSIC` 保留。界面暂不增加主题切换设置。

## 图标

`icons/` 保存原始 SVG，应用中的 `ic_portal_*` VectorDrawable 使用同一条路径。

- 统一 24 × 24 viewBox，描边 1.7，圆端点与圆连接。
- 图形保持比例，不拉伸；常规控件使用 24dp，品牌标识可等比放大。
- SVG 使用 `currentColor`；Android 端通过主题 tint 适配明暗模式。
- 功能图标保持单色，绿色底色由容器提供，危险色由操作语义决定。

## 导航与设置

抽屉按定位、模拟、运行、其他分组，使用圆角选中容器。品牌头部只展示 Portal、几何图标和运行状态摘要；摘要仅在状态或后端变化时更新。

设置目录包含地图与定位、运动与摇杆、卫星与 GNSS、分应用规则、系统与环境模拟、高级与实验、后台与隐私、关于与更新。分类使用独立 Fragment destination，保留返回栈与页面重建状态；持久化键和设置读写 API 不变。

“恢复并启动上次场景”位于运行页。地图与定位作为相连圆角分组的详情页样板，参数旁保留单位，组下说明生效时机。
