# 默认目标天空启动验证

2026-11-21：启动 Xposed 定位时，若系统模块认证、协议与 Hook 安装状态有效，且 Root 实现或框架系统范围能力可用，则为未设置过卫星启动选项的用户默认开启目标天空（AUTONOMOUS）。不会因打开应用就开始定位，也不会切换用户所选的定位后端或自动启用 Native。

已选的实测回放继续使用原采集来源；来源缺失或过期仍按原规则提示，不自动改成目标天空。显式关闭卫星模拟的设置也会保留。标准无 Root 后端及不可用的模块连接不会应用这些默认值。

Root 判断兼容应用看不到 `su` 的情况：先读取 libxposed 的 `PROP_CAP_SYSTEM`，并要求实际的系统模块认证；可见的 Root 实现版本只作回退，探测限制为一秒且在后台执行，不请求额外提权。

本机 253 个应用单元测试、应用 lint、Android 测试编译及 47 个 Python 测试通过。策略测试覆盖缺少 Root、模块不可用、默认目标天空、已有回放/自动策略、显式关闭，以及默认值重复应用。

Redmi K50 / Android 14 / HyperOS 2 / KernelSU / LSPosed 7944 的结果：

| 检查 | 结果 |
| --- | --- |
| 应用 UID 的 su 可见性 | 被 KernelSU 隐藏；通过系统范围能力识别，未要求新 Root 授权 |
| 未选卫星选项，启动定位 | 自动保存 AUTONOMOUS 并开启卫星模拟 |
| 主动选择实测回放 | 准备后仍为 REPLAY，没有改成目标天空 |
| 主动关闭后重新启动定位 | 卫星模拟保持关闭 |
| 独立包名与 UID 的接收端 | 8 次 GNSS 状态、最多 59 颗卫星、178 条 NMEA、42 次 GPS 回调；未取得控制凭据 |
| Native | 未加载、未启用 |

最终后端设备测试通过，无 assumption 跳过。该测试使用预先授予的定位权限，直接检查后端，不依赖地图页面或测试 runner 替应用授权；未把 MIUI 的授权失败或跳过计作通过。
