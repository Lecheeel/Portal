# GNSS 采集与回放

Portal 的 GNSS 模型先使用设备真实回调建立画像，再决定是否允许统计回放或广播星历几何。采集窗口为 30–300 秒，要求停止所有模拟、开启系统定位并授予精确位置权限。每帧保存星座、SVID、仰角、方位角、CN0、`usedInFix`、星历/年历标志；可用时同时保存原始测量和导航电文。

状态回调有帧但每帧 `satelliteCount=0`，或所有信号 CN0 为 0、没有有效观测点时，采集不会生成画像。系统会显示“等待真实采集/画像不可用”，也不会补出固定 5 颗、12 颗或 31 颗卫星。窗边、室内和遮挡环境出现这种结果属于接收条件问题，应在开阔天空重新采集。

画像中的星座比例按所有采样帧的卫星样本计算，并保留每帧数量分布、在用比例、仰角/CN0 分布和区间置信度。`min_satellites=0` 表示自动，使用当前有效画像；正数只表示可见卫星下限，超过真实有效池时返回实际数量并记录诊断。任何路径都不会为了满足下限制造地平线以下卫星。

统计回放保持采集到的卫星身份和相邻帧连续性，不把统计天空冒充精确轨道。广播几何只有在时标、健康状态、有效期和坐标系证据齐全时启用：GPS 使用同次开机的 GPS 时钟，Galileo 需要独立 GGTO，北斗使用明确的 BDT/BDCS 证据。GLONASS 还要求同次开机的 UTC(SU)+3h 连续时钟、PZ-90 实现、广播有效期和经过验证的 WGS-84 到 PZ-90 接收机变换；缺任一项就保留统计回放，不猜时间偏移或坐标转换。

仰角和方位角来自 ECEF 到 ENU 的几何变换；DOP 由视线矩阵的 QR 求解得到。秩不足、条件数过大或观测数不足时报告无有效三维定位解，`usedInFix` 会被清除，不能用 `coerceAtLeast` 伪造 DOP。

GnssStatus、NMEA 和 Location extras 都从同一个带序列号的 `GnssFrame` 生成。没有有效 frame 时，Location extras 不写卫星字段；NMEA 的 GGA/GSA/GSV 数量和身份必须与该 frame 一致。
