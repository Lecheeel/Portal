# Location Integrity v0.1.0

首个独立定位观测与实验对比版本。可与 Portal 同时安装，无需 Root、无需 Xposed、无需成为模拟位置应用。

- Android 8 / API26 起，通用 APK，无 Native ABI 依赖。
- GPS/Network/Passive/系统 Fused 定位观测，缓存标识、Mock 标记、字段及每渠道回调间隔统计。
- GNSS 卫星、NMEA、原始测量/时钟与加速度计、陀螺仪快照。
- 区分直接模拟标记、启发式异常和普通信息；不提供虚假的“100% 真实定位”分数。
- 支持近似位置权限降级、前台通知停止、手动时间线标记、本地实验保存、两次对比及 JSON 导出。
- 独立签名，APK Signature Scheme v2/v3；公开证书摘要与 APK SHA-256 随发布附带。

安装 LocationIntegrity-v0.1.0.apk。精确定位权限可启用 GNSS 观测；近似定位也可以开始，缺失信息会明确显示。
不申请 Internet、后台位置或模拟位置权限。日志含坐标，默认仅本机保存，导出时由用户选择文件位置。

这是实验工具首版。规则阈值尚未用实机数据集校准；系统/应用 Hook 可影响观测，其他应用的定向伪造不一定可见。
本版不包含 GMS SDK、Wi-Fi/基站地理数据库、连续传感器波形或 RF 欺骗检测。
最近 2000 个定位样本、80 条 NMEA 和最新 GNSS/传感器快照会随报告保留；不是无限原始数据录制器。
