# LocationService v1.2.0

- 首页取消中心准星。点击地图、搜索或输入坐标后，通过底部卡片确认切换；拖动和缩放不再改变模拟位置。
- 首次真实定位增加独立的绿色原始位置标记，模拟期间仍可查看，切换页面和旋转后保留。
- 路线支持道路规划、逐点添加和手指画线。画线模式单指绘制、双指移动／缩放，可撤销上一点或上一笔，草稿自动恢复，支持保存和保存并启动。
- 后端与运行状态改为概览卡片及折叠分组；日志支持筛选、分页展开、复制和清空视图。
- 补充深色界面配色及路线、手势、页面交互回归检查。

手动点／笔之间按直线连接，不自动贴合道路。地图显示及在线搜索仍需要有效的高德配置和网络。原始位置记录本次会话首次取得的非模拟定位；如果启动模拟前未能取得真实定位，会明确显示尚未获取。

Android / ROM 的实际定位消费者、Xposed 和实验性 Native 行为仍依赖设备环境；本版本保留已有的 Bugly x86_64 16 KB 页对齐限制。
