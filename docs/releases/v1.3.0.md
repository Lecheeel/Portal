# LocationService v1.3.0

- 授予悬浮窗权限后，默认显示最小化摇杆按钮，点击展开，支持再次最小化、拖动并保存位置。
- 悬浮窗独立于主页面管理，切换页面、页面重建及停止模拟时不再主动隐藏；在主页手动关闭后记住选择。
- 未模拟、暂停或播放路线时显示对应状态并禁用手动移动；关闭悬浮窗时结束摇杆移动。
- 清理摇杆重置后的延迟方向锁定任务，补充悬浮窗切换、页面重建与关闭行为的界面回归测试。

悬浮窗需要系统授权。持续显示有助于保持应用可见，但不能保证阻止小米等系统冻结或终止进程；对高德位置回跳的改善效果仍需真机验证。

提供 arm64、x86_64 及通用 APK。小米手机通常选择 arm64 版本。保留已有的 Bugly x86_64 16 KB 页对齐限制。
