# LocationService v1.4.0

- 新增设置项“提交前清除模拟标记（实验）”，默认关闭，仅用于无 root 标准模拟模式。切换后下次定位提交生效，其他定位参数和上报间隔保持不变。
- 开启后尝试通过反射修改本地 Location 的模拟标记，失败不阻断定位提交。在“后端与运行状态 → 能力与诊断”刷新可查看 MOCK_FLAG_EXPERIMENT；日志区分本地调用完成和反射不可用，不将其视为系统或高德已接受定位。
- 项目与 CI 工具链同步升级：Android SDK Build-Tools 37.0.0、NDK 30.0.16248370、CMake 4.1.2。
- 补充反射实验的数据完整性测试及诊断不阻断发布的回归测试。

重要：提交前的 Location 本来就可能没有模拟标记。Android 接收到测试位置后仍可能重新标记为 mock，本实验不保证隐藏模拟定位，也不保证解决高德静止后回跳。请保持其他设置一致，对照开关前后的表现。

提供 arm64、x86_64 和通用 APK，小米手机通常选择 arm64。保留已有的 Bugly x86_64 16 KB 页对齐限制。
