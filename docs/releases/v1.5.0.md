# LocationService v1.5.0

- 悬浮窗展开后可直接调节速度：没有活动路线时显示“摇杆速度”，路线播放或暂停时显示“路线速度”。支持滑块和每次 ±0.1 m/s 微调。
- 调速实时应用于当前场景，不需要重新启动。暂停时可预设恢复后的速度，设为 0 时停止移动；路线进度、摇杆方向和锁定状态保留。
- 面板显示设定速度，静止或暂停时不会被定位样本的 0 速度覆盖；重新启动其他场景时同步其速度配置。调节值同时保存为设置中的默认速度，已保存场景的独立配置保留。
- 补充运行中调速、暂停恢复、零速度、失败清理及悬浮窗交互回归测试。

提供 arm64、x86_64 和通用 APK。小米手机通常选择 arm64，可覆盖安装升级。
