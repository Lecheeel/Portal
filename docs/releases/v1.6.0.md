LocationService v1.6.0 增加路线交换、运动控制和无 Root 诊断能力。

- GPX 轨迹／路线导入、单条及全部路线导出，分别保存不同轨迹段。
- 可选路线平滑加减速及弯道减速，保留实际经过时间推进。
- 摇杆幅度调速、中心死区、动画归中、锁定振动；新增步行／跑步／骑行／驾车预设与 km/h 显示。
- 圆周微动周期独立可调，松手后以当前位置为圆心。
- 后台设置引导：电池优化、精确位置、通知状态及小米自启动入口。
- 持久化限量诊断历史、文本导出、实际提交间隔／耗时统计；明确丢失的 Provider 有限恢复。
- 可选系统 Fused 和 GMS 融合定位通道，默认关闭；失败保留标准 GPS／Network，停止时清理。
- 标准模式默认启用启动密集提交：初次提交后额外五次，目标间隔 80ms，随后恢复场景间隔。

GMS 需要可用的 Google Play 服务。可选通道、微动和清除标记实验不保证所有目标应用接受定位，也不保证小米／高德不回跳。已保存场景使用自身运动参数；新的设置用于下次启动。

Android 12 / API 31 及以上。普通安卓手机选择 arm64 APK；all APK 同时包含 arm64 和 x86_64。保持既有发行签名。Bugly x86_64 的 16KB 页对齐警告仍存在。
