LocationService v1.7.0 优化界面组织、浅色／深色视觉和高频运行时的显示开销。

- 资料库使用路线／场景／地点标签、名称与坐标搜索、矢量空状态和复用列表；导入／导出集中到菜单。
- 设置按定位参数、运动、定位通道与实验、系统 Hook、后台与版本分组；数值和说明分行，扩大触控区域。
- 单点定位改用带常驻标签的坐标输入卡片，主操作与运行控制分开。
- 运行中心统一卡片与展开图标，展开底部章节时自动显示首批操作，隐藏详情不再持续格式化。
- 首页搜索、抽屉、路线编辑与悬浮摇杆统一配色；搜索操作提供 48dp 触控区域，路线编辑按钮分两行。
- 系统栏图标随浅色／深色主题切换，导航标题统一中文；资料库旋转到横屏时收起装饰标题，保留列表空间。
- 仅限制界面样本刷新频率，定位提交间隔不变；暂停、错误、场景和后端变化立即更新。列表搜索与差量计算移到后台，设置页仅在后端改变时重绘能力。

保留现有发行签名，Android 12 及以上。普通手机选择 arm64 APK。性能验证包含高频状态流和 1000 条记录的复用列表；不代表所有真机均达到固定帧率。高德与厂商后台调度行为不由本轮 UI 改动保证。既有 Bugly x86_64 16KB 对齐警告仍存在。
