# 🚀 LocationService · 核心重构与体验升级

本次更新集中重构定位、GNSS/NMEA、环境与传感器链路，迁移至现代 libxposed API，并重新整理导航、运行中心和设置页面。

## 🛰️ GNSS 与定位模型

- 新增：GPS、北斗、GLONASS、Galileo、QZSS 多星座天空模型，统一生成卫星方位、仰角、CN0 与参与定位状态。
- 新增：同源 NMEA 生成，覆盖 GGA、RMC、GSA、GSV、GST、ZDA，统一处理时间、校验和与卫星数量。
- 新增：GNSS/NMEA 主动投递，在模拟启用后可独立于真实 GNSS 回调输出数据。
- 新增：基于 Kepler 轨道传播的实验性天空模型，可在设置中切换。
- 优化：GPS、Network、Fused 差异化定位画像，完善精度、延迟、字段策略与可选物理微漂移。

## 环境模拟与分应用控制

- 新增：WiFi／基站环境采集、保存与回放，支持搜索、重命名和 JSON 导入导出（实验性）。
- 新增：程序化 WiFi 环境，使用固定种子、网格化 AP 和 RSSI 路径损耗模型生成扫描与连接信息（实验性）。
- 新增：自建 WiFi 指纹库导入与回放，以及环境来源、基站画像和 SIM 状态配置（实验性）。
- 新增：分应用排除与固定点，为使用系统定位接口的应用配置独立定位规则（实验性）。
- 新增：恢复上次场景配置；分应用规则和环境配置支持运行中更新。

## Native 与 Xposed

- 重构：全面迁移至 libxposed API 102 原生 Hooker／Chain，移除 legacy 兼容层，重整 Hook 生命周期与反射调用。
- 新增：Native + Xposed 传感器扩展，由统一 SensorFrame 驱动加速度、陀螺仪、地磁、气压等事件改写（实验性）。
- 优化：步频根据速度和步幅连续变化，支持缩放与变化幅度调节；Native 负责帧缓存、插值和事件应用。
- 优化：Native 模式自动加载与启用，覆盖 HIDL／AIDL 传感器转换路径，调整载荷混淆打包及加载后的文件清理。
- 优化：system_server Java Hook 热重载与目标进程重注入流程；Native 更新继续使用重启流程。
- 优化：跨进程配置与样本协议、不可变运行快照，以及定位字段、Provider、AppOps、Settings 和模块元数据的查询处理。
- 修复：原始 GNSS 监听注销、NMEA 注册与回调处理中的问题。

## ✨ 界面与操作

- 优化：位置与卫星功能合并为“模拟”入口，通过双页签切换。
- 优化：运行中心前置当前状态，整理设备授权、模式选择、能力诊断和日志。
- 新增：选择实验性 Native + Xposed 模式时的风险确认。
- 优化：环境采集、WiFi 指纹库和回放配置移至独立“环境工具”页面。
- 优化：设置分组与辅助说明，移除小半径圆周运动相关控件，统一卡片、间距、按钮和深浅主题。

### 升级提示

- Xposed 模式需要支持 libxposed API 102 的框架，升级后请确认模块作用域并按提示重启。
- Native + Xposed 需要 Root、arm64 设备和已激活的 Xposed。停止模拟不会卸载已加载的 Native Hook，卸载或更新需重启相关进程或设备。
- Native 传感器、环境模拟和分应用能力仍为实验性；计步事件投递受硬件与 ROM 限制。
