# 自主 GNSS 天空生成

目标是按模拟地点、时间和环境生成天空，真实采集用于校准或明确的实测回放。首次安装、长期室内、画像过期和完全离线都不能阻断自主模式。

## 模式与数据职责

- 自动：按目标地点计算几何，自动选择适用轨道来源。
- 自主：不依赖本机采集，允许网络、离线资源和虚拟兜底。
- 回放：保留采集地、采集时间和接收过程，不将原始角度解释为异地天空。
- 关闭：不注入合成 GNSS 状态。

来源优先级为广播星历、历书、仍适用的离线轨道数据、明确的虚拟天空。具体卫星的时间、健康及有效性由对应适配器检查，不共用画像的 24 小时门限。环境校准的生命周期也独立管理。

全局轨道位置可共享；每条分应用路线的 ENU 投影、遮挡和接收状态必须独立。轨道几何不代表真实 CN0、完整导航观测或定位成功。

最低数量 0 表示自动，正数表示可见数量下限。物理优先不足时报告缺口；数量保证在已验证的协议容量内补充明确的虚拟身份。禁止重复身份、抬升真实地平线下卫星或伪造 DOP。可见、跟踪、在用分别建模。

## 已选定的计算约束

- Yuma 的倾角已经是绝对弧度，不能重复加 LNAV 的标称倾角。
- 截断 GPS 周在资源导入时依据独立的近似日期解析；持久化后不随模拟日期重新解析。
- 历书绝对龄期在周期归一化前检查，旧周不能通过回绕冒充当前资源。
- 历书传播使用 GPS 规范中的方程，缺失修正项置零；不构造伪造的广播 IOD 或 fit interval。
- 历书预算是应用策略，不是规范承诺的统一精度有效期；下载时间不能重置参考时刻。
- UTC 资源过期不能永久假定 GPS−UTC 为 18 秒。POSIX 无法表达的闰秒也不伪造时间戳。
- 虚拟轨道资源声明自己的参考时刻、拓扑和坐标方向，不冒充真实轨道上传。
- `hasEphemeris`、跟踪与在用标志必须来自接收机状态及可用导航依据。
- 多系统独立钟差模型需要足够观测且矩阵满秩；不采用固定四星判断所有定位解。

## 完成验收

- [ ] 首次安装、从未采集且离线，在支持 GNSS 注入的后端仍输出自主天空。
- [ ] 画像过期或损坏不关闭自主引擎；关键配置和认证错误仍正常失败。
- [ ] 相同 UTC 更换目标地点后，局部几何和可见性随地点改变。
- [ ] 多路由各自独立，避免混入采集地或其他路线的局部几何。
- [ ] 物理优先和数量保证行为不同，容量不足明确提示，无静默截断。
- [ ] 稳态仿真不周期性重放一次采集中的冷启动无星阶段。
- [ ] 来源切换在统一发布帧边界生效，序号连续，监听器不重复注册。
- [ ] GNSS 状态、NMEA 和 Location extras 同源，身份和数量可由独立接收端核对。
- [ ] 高数量通过 Android、NMEA 和接收端验证，不能仅以设置允许 128 为依据。
- [ ] 轨道与 DOP 有独立计算证据，无负仰角输出、重复身份或伪造有限 DOP。
- [ ] 覆盖跨日、重启、网络失败、损坏更新、来源过期及长期运行。
- [ ] 区分标准 Mock、Xposed 和当前 Native 能力，修正旧 README 与现状文档。

## 依据与离线资源来源

- [IS-GPS-200N](https://archive.gps.gov/technical/icwg/IS-GPS-200N.pdf)：20.3.3.5.2.1–2、Table 20-IV，历书的近似计算、参考周和龄期说明。
- [CelesTrak Yuma 定义](https://celestrak.org/GPS/almanac/Yuma/definition.php) 与[公开历书入口](https://celestrak.org/GPS/almanac/Yuma/almanac.yuma.txt)：离线 GPS 资源来源。具体下载时刻、摘要与参考时刻保存在资源自身。
- [IERS 闰秒资源](https://hpiers.obspm.fr/iers/bul/bulc/ntp/leap-seconds.list)：保留原始元数据及 public-domain 声明，按文件中的有效期使用。
- [IGS MGEX](https://igs.org/mgex/data-products/) 与 [BKG 导航归档](https://igs.bkg.bund.de/root_ftp/IGS/BRDC/)：后续多系统广播资源候选；尚不能视为已完成运行链路验证。
